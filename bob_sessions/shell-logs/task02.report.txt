### 6. `EffectVector.canonical_bytes()` determinism â€” [`core/models.py`](core/models.py:119)

The method is deterministic for three compounding reasons:

1. **Sorted collections:** `domains` and `paths` and `network_targets` are all passed through `sorted()`, which eliminates insertion-order variance. A vector built with `domains=["VCS_REMOTE","UNKNOWN"]` produces identical bytes to one built with `domains=["UNKNOWN","VCS_REMOTE"]`.

2. **`sort_keys=True` in `json.dumps`:** All dict keys are serialized in lexicographic order regardless of Python dict insertion order, eliminating CPython dict ordering variance.

3. **Fixed `separators=(",", ":")`:** No optional whitespace. A single canonical byte sequence is produced regardless of Python version or platform locale.

4. **Excluded mutable / contextual field:** `observability` and `reason` and `raw_input` are intentionally omitted from the canonical payload. Only the action-binding fields (what was proposed, where it would go, what domains, what decision) are signed. This is the correct design: the signature binds the action semantics, not the explanation text.

âœ… **Determinism is structurally guaranteed, not accidental.**
