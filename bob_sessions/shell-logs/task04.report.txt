### 7. Why the hook checks `stdin.isatty()` before reading input

[Line 68](scripts/hooks/pretooluse.py:68): `raw = sys.stdin.read() if not sys.stdin.isatty() else ""`

When a developer runs the script directly in a terminal (e.g. for testing), `stdin` is a TTY and `sys.stdin.read()` would block indefinitely waiting for keyboard input. The `isatty()` guard short-circuits to an empty string in that case, causing the hook to return `0` (allow through) rather than hanging â€” preserving normal developer ergonomics while still processing the structured JSON that Bob pipes in during a real hook invocation.
